# Telecom Customer Churn Analytics

## Project Overview

This project analyzes customer churn for a telecommunications company.

## Business Objective

The objective is to identify customer segments associated with higher churn and provide actionable business insights.

## Technology Stack

- Oracle XE
- SQL Developer
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- Git
- GitHub
- JIRA

## Project Workflow

Business Requirement
→ Data Collection
→ Data Quality
→ SQL Analysis
→ Python EDA
→ Power BI Dashboard
→ Business Insights

## Key Business Questions

1. What is the overall customer churn rate?
2. Which contract type has the highest churn?
3. Which payment method has the highest churn?
4. Does customer tenure affect churn?
5. Does monthly charge affect churn?
6. Which internet service has the highest churn?
